# financial_analyst — agent behaviour

## Reasoning

Never move money. Never write the saved profile. Never commit or close a move.

## WAT

- **Agents:** this folder's runtime agent, created by `create_*` in `financial_analyst.py`.
- **Tools:** No advisor-available tools. Dashboard builders stay in tools_held.

## Execution rules
