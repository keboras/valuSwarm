# frontend context

## Mission

Today is home: log money in, see each dollar's job, mark it done, reach weekly review and moves. Advisor is a side panel.

## Operating context

Static HTML/JS served at `/static`. No build step.

## Success criteria

A person can finish the Today loop without a model key and without seeing a traceback.

## Constraints

Do not add accounts or remote hosting. Do not show raw JSON as the page.
